# 25 - Source register

Status: research draft (2026-11-26). Evidence classes per 01-research-methodology.md.

## Summary

- The package registers **375 external sources** from 14 agent fragments. They are merged into `data/source-register.csv`; the statistics are in `data/source-register-stats.json`.
- Both files are generated by `python3 -I scripts/merge_source_register.py`. Running it with `--check` fails if either file is stale, if two sources share an ID, if any `[CODE-NNN]` citation in a package Markdown file does not resolve, or if a source lacks a URL, evidence class or access date. The check passes on 2026-11-26.
- **Inline citations.** 283 sources are cited inline in the Markdown. The other 92 are cited only from data files, through the `used_in` column or the `source_ids` columns of the CSV registers. Some are background reads kept for provenance.
- **Internal sources.** Files in daf-landscape and unbound are cited by repository path in the text and are not registered here.
- **Access date.** All sources were accessed on 2026-11-26. Pages change, so a page read after that date may differ.

**Reading the evidence class.** The class describes the claim the source supports, not the source's general quality. A vendor's own documentation of its API terms can support a VERIFIED-FACT about those terms. The same vendor's claims about its coverage are VENDOR-CLAIM.

**Self-reported counts.** After the adversarial review (ADVA-19), counts that a sponsor or vendor publishes about itself are VENDOR-CLAIM even when High confidence. Examples: Fidelity's 227,000 charities and Vanguard's 66,785. Counts from Form 990 filings and audited statements remain VERIFIED-FACT, with a note that they are self-reported filings.

## Known limitations

- **Documents not read first-hand.** Several are recorded as evidence gaps (24, E18) or as session-local reads:
  - the Slaughter and May TSB report (image-only PDF);
  - the Queensland Health inquiry report (HTTP 403);
  - G2/Capterra review pages (403);
  - Charity Commission and ACNC bulk pages (403 or robots-blocked);
  - the MS GIFT donor circular (text not extractable).
- **Robots.txt.** One IRS request redirected to a robots-disallowed TEOS bulk-download page. The copy was used once and not fetched again (disclosed in 04).
- **Vendor documentation** describes products as offered, not as contracted or as performing.
