# Competitive advantage creation (Phase III)

Date: 2026-11-26. Status: research from public sources and the owner's repositories. **Not legal, tax or investment advice; not a launch authorization; no expenditure is approved.** Every economic figure is conditional on labelled inputs, and nothing is measured. Agents, reviewers and integrator are the same model family, so nothing here is independent validation.

Start with [00-executive-summary.md](00-executive-summary.md). Answers to the twenty executive questions are in [26-final-recommendations.md](26-final-recommendations.md).

**Baseline:** owner-approved DEC-001..012 and owner decisions OD-P3-01..04 ([01](01-approved-strategic-baseline.md)). Phase III proposals (P3-DEC-) are not approved; see [25](25-executive-decision-register.md).

## Layout

- Reports `00`-`26`.
- `data/registers/`: merged registers, generated by `model merge` from `data/fragments/`.
- `data/evidence/`: agent working notes and the adversarial reviews.
- `data/model-inputs/` and `data/model-outputs/`: F# model inputs and outputs.
- `model/`: F# model and validator ([README](model/README.md)).
- [research-ledger.md](research-ledger.md).

## Reproduce and validate

```bash
cd model
dotnet test tests/CompetitiveAdvantageCreation.Tests
dotnet run --project src/CompetitiveAdvantageCreation -c Release -- check ../data/model-inputs ../data/model-outputs
dotnet run --project src/CompetitiveAdvantageCreation -c Release -- merge ..
dotnet run --project src/CompetitiveAdvantageCreation -c Release -- validate ..
```
