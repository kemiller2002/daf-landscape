# Endaoment API
Use the Endaoment API to authenticate donors, open and fund DAFs, search nonprofits, and submit grants. Everything is REST over HTTPS.
> [!NOTE]
> See [Rate limiting](https://docs.endaoment.org/developers/quickstart/error-handling.md#rate-limiting) for current limits by environment and how to request more headroom.
